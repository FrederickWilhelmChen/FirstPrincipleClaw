# FirstPrincipleClaw

> 思维的背景板 - 帮你砍掉 90% 的复杂度

## 核心理念

在 AI 时代，我们需要的不是更多功能，而是更清晰的思维。

FirstPrincipleClaw 不是偶尔用一次的工具，而是你思维的背景板，始终提醒你：
- 这个问题真的需要这么复杂吗？
- 哪些是可以砍掉的？
- 最简单的方案是什么？

## 产品形态

**Skill（核心逻辑）+ 轻量级 Web UI（可视化）**

- 实时监控你的思维复杂度
- 主动提醒过度设计
- 展示问题压缩率

## 特性

- 🎯 **第一性原理分析** - 拆解问题到本质
- 📊 **复杂度可视化** - 实时展示问题复杂度
- 💡 **主动提醒** - 识别可以砍掉的部分
- 📈 **历史记录** - 看到自己的简化进步
- 🎨 **极简设计** - 清爽的 UI，专注于思维
